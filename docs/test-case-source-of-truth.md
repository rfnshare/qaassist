# Test Case Source Of Truth

Test cases are not only human checklist items. They should become structured source-of-truth assets readable by QA, AI, Azure Test Plans, and future automation.

Each approved test case should eventually include:

- Source references.
- Scope references.
- Priority and risk.
- Preconditions.
- Test data.
- Steps.
- Expected result.
- Manual/automation status.
- Execution evidence.
- Linked defects.
- Linked automation.

Approved test cases can later be pushed to Azure Test Plans and linked to the story after user confirmation.
