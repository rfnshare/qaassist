# Manual Testing Workflow

The manual testing companion should help QA execute work without replacing judgment.

Future capabilities:

- Guided execution from approved test cases.
- Step-by-step assistance.
- Notes and evidence capture.
- Screenshot/video attachment planning.
- Bug creation from current context.
- Retest for resolved bugs.
- Story ready-for-UAT handoff.

Nothing should create bugs, update states, attach evidence, or mark UAT readiness without user approval.
