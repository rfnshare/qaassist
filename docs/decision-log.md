# Decision Log

## Accepted: Browser Extension First

Status: Accepted

QA Assist should start as a Chrome/Edge browser extension so QA engineers can work inside existing tools without context switching.

## Accepted: Azure DevOps First

Status: Accepted

Azure DevOps Boards / Work Items is the first supported platform.

## Accepted: Backend From Early Stage

Status: Accepted

A backend should be introduced early to mediate LLM access, integration calls, auth, validation, and privacy boundaries.

## Accepted: Structured Output

Status: Accepted

QA analysis should be returned as structured data first, with Markdown rendering as an output format.

## Accepted: No Direct Codex Login Reuse

Status: Accepted

QA Assist must not reuse Codex, ChatGPT, VS Code, browser, or unrelated application tokens.

## Accepted: Playwright Later

Status: Accepted

The MVP should mark automation candidates. Full Playwright code generation is a later capability.
