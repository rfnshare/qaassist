# Automation Strategy

Playwright is the first UI automation target. API automation comes later.

Future repository modes:

- Local repository.
- GitHub.
- Azure Repos.
- QA Assist-managed workspace.
- Manual export fallback.

Automation should be generated from approved source-of-truth test cases only. User approval is required before code changes, branch creation, PR creation, CI changes, or automation execution that affects shared systems.
